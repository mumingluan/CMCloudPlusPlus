## 0.1.3 会话、哈希与构建

多账号 vault 自动从单账号格式迁移。测试验证旧凭据保留、第二账号持久化、断开后不自动连接、密码/验证码清除，以及全局哈希设置变化不改变现有 TB 任务的策略。连接切换沿用账号/空间隔离并暂停原空间任务。新增回归验证跨账号上传可复用同一源文件，下载目标仍全局保护，不能与任何未完成读写任务争用本地路径。前端测试覆盖切换的重复提交保护与移除确认；没有两个真实账号用于跨账号服务联调。

真实个人空间请求在缺失 `contentHash`/`contentHashAlgorithm` 时返回 `04000002`，消息为“文件内容hash或算法名不允许为空”；启用 `parallelUpload` 仍拒绝。实现因此对个人空间保留真实 SHA256 预计算，跳过选择只在群组流式路径生效。群组免预哈希路径沿用参考驱动的已有协议，本轮没有群组账号实测。上传断点保留服务端确认和源文件变化检查。

桌面与 390px 手机明暗主题、侧栏底部会话/设置、68px 桌面收缩和上传策略选择经过浏览器预览核对，无页面横向溢出，手机导航控件为 48px。机械设计检查只有 85 项 advisory，主要为既有尺寸偏离文档类型阶梯，无阻断项。浏览器截图使用明确示例数据。

快速脚本关闭 LTO、使用 16 个代码生成单元并启用增量编译；正式优化仍可用 `-Production`。Windows 首次快速构建总用时 159.11 秒，随后含前端/窗口主题权限变化的增量安装包为 54.36 秒。Android 的 Gradle 插件在脚本调用 CLI 已成功编译并暂存库时逐字节 SHA256 比对后复用库，省去第二轮 Cargo；IDE 默认构建流程保留。首个可用 Android 增量 APK 共 97.64 秒，其中原生编译 4.27 秒，另包含 Gradle 插件检查及 APK 装配。Windows 符号链接的 Java canonicalPath 不等于源路径，因此库复用检查采用内容摘要比对，拒绝内容不一致的暂存库。

## 大文件和队列验证边界

自动化测试包含持久化恢复 10,000 个任务以及 TB 量级偏移等边界；这验证数值及数据库恢复路径。尚未进行实际 TB 文件网络传输、长时间断网恢复、服务端超大文件限额或大型账号目录的压力联调。

当前实现边界：

- 待处理队列上限 100,000 项，每批最多 10,000 项；单次目录扫描最多 100,000 项。
- SQLite 使用 WAL；队列绑定账号与空间；传输界面每页查询 200 项并虚拟渲染。
- 上传按 100/512 MiB 默认分片和流式 I/O 处理；新版 SHA256 校验完整读取一次文件，耗时随文件规模增加。
- 下载恢复校验 Range 响应和偏移；同名下载不覆盖已有文件。上传分片进度按服务端确认持久化。

## 官方会话与凭据保护

官方导入读取当前用户的桌面配置，以只读文件解析 Chromium LevelDB 会话；发现阶段只读路径和版本元数据。只选择当前 `UserInfo`，导入后通过云盘服务验证。

Windows vault 使用当前用户 DPAPI。移动端 vault 使用 AES-256-GCM，包装密钥位于应用私有目录，以 Unix `0600` 权限保存；硬件 Keystore/Keychain 绑定尚未实现。密码和验证码不持久化，凭据不发送至前端账号摘要。

## Android 平台边界

### 16 KiB 页兼容

已完成 debug APK 和最终 release 预览 APK 的 arm64 原生 ELF 与 ZIP 对齐检查。最终签名 APK 实际提取的 `libcmcloud_lib.so` 全部 LOAD 段对齐为 `0x4000`，GNU_RELRO 结束地址满足 16 KiB 对齐；APK 内原生库与构建输出的 SHA256 一致。嵌入的前端资源为 `index-SsXsJ4fr.js` 和 `index-D1i3T5QC.css`，与最终生产构建一致。Android 官方要求还需在 16 KiB 环境实际运行；仅对齐检查不能替代设备运行验证。[Android 16 KB 页大小说明](https://developer.android.com/guide/practices/page-sizes)。

可对最终 APK 执行：

```powershell
& "$env:ANDROID_HOME\build-tools\37.0.0\zipalign.exe" -v -c -P 16 4 .\releases\CMCloudPlusPlus-0.1.4-android-arm64-preview.apk
adb shell getconf PAGE_SIZE
```

`PAGE_SIZE` 应在用于该项测试的设备上返回 `16384`。本轮未完成 16 KiB 真机/模拟器安装及运行验证。

### 文档选择器和下载导出

上传使用 SAF 的文件或目录授权。当前单次文件选择上限为 64，持久授权预算为 128；选择文件夹只占一个目录授权，可递归扫描子目录。持久授权仍可能因源文件移动、删除或提供者行为而失效，恢复时需要重新选择。[Android 共享文档访问说明](https://developer.android.com/training/data-storage/shared/documents-files)。

下载保存到应用私有 `Downloads`，完成后通过 FileProvider 打开或使用 `ACTION_CREATE_DOCUMENT` 导出。导出采用 64 KiB 缓冲流式复制，需要目标空间容纳额外副本，需保持应用打开，当前没有导出断点续传。SAF 云端提供者、外置存储、大文件导出和授权重启恢复仍需真机验证。

最终 APK 清单中原有文件组件为 `io.cmcloud.plus.fileprovider`，独立下载组件为 `io.cmcloud.plus.downloads`，均 `exported=false`；下载组件仅通过 `../io.cmcloud.plus/Downloads/` 开放应用下载目录。最终 APK 只含 `arm64-v8a`，最低 API 24、目标 API 37。本轮 `adb devices` 没有连接设备，未执行安装或实际文件打开与导出。

### 前台服务

传输声明 `dataSync` 前台服务，并处理超时回调、通知及唤醒锁。Android 15 及以上针对相应目标版本的应用，后台 `dataSync` 前台服务在 24 小时内共享累计 6 小时时限；到达时限后应用需及时停止服务。当前实现停止服务并保留持久化队列，提示返回应用继续。[Android 前台服务时限说明](https://developer.android.com/develop/background-work/services/fgs/timeout)。

尚未完成真实设备上的通知拒绝、锁屏、电量限制、系统回收、服务超时及长时间后台网络传输验证。
